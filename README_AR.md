# Mobile Transfer Pro — نسخة تجريبية أولى محسّنة

مشروع Windows 10 بواجهة عربية لنقل **الملفات المشتركة المتاحة** من هاتف Android إلى هاتف Android آخر عبر ADB. هذه ليست أداة نقل كاملة لكل بيانات الهاتف، ولم تُختبر بعد على أجهزة فعلية.

## ما يفعله هذا الإصدار
- اختيار يدوي منفصل للمصدر والوجهة، مع منع اختيار الجهاز نفسه.
- تحديث قائمة الأجهزة المتصلة وتبديل الاتجاه.
- اختيار مجلدات: DCIM، Pictures، Movies، Download، Documents، Music، ووسائط واتساب التي يتيحها النظام.
- تأكيد صريح قبل النقل.
- نقل الملفات إلى مجلد جديد على الهاتف الهدف، دون حذف بيانات المصدر أو الكتابة المقصودة فوق مجلدات المستخدم الأصلية.
- فحص استمرار اتصال الهاتفين قبل كل مرحلة نقل.
- سجل وملخص للمجلدات الناجحة والمتعذرة.
- خيار إبقاء نسخة العمل المؤقتة على الكمبيوتر أو حذفها بعد المحاولة.

## غير مدعوم في هذا الإصدار
- نقل التطبيقات نفسها أو بياناتها الخاصة أو الحسابات وكلمات المرور.
- قواعد محادثات واتساب/ماسنجر الداخلية، أو الرسائل SMS، أو سجل المكالمات، أو جهات الاتصال.
- نقل iPhone أو النقل بين Android وiPhone.
- النقل عبر Wi-Fi من داخل الواجهة، واستئناف عملية منقطعة، وفحص التكرار والتحقق من سلامة كل ملف.

## أسهل طريقة لبناء ملف EXE على Windows 10
1. نزّل وثبّت **.NET 8 SDK** الرسمي: https://dotnet.microsoft.com/download/dotnet/8.0
2. فك ضغط المشروع كاملاً في مجلد عادي، مثلاً `C:\MobileTransferPro`.
3. افتح المجلد، اضغط بزر الفأرة الأيمن على `Build-Windows.ps1` واختر تشغيله باستخدام PowerShell، أو افتح PowerShell داخل المجلد وشغّل:
   `powershell -ExecutionPolicy Bypass -File .\Build-Windows.ps1`
4. السكربت ينزّل Android Platform-Tools من Google إن لم تكن موجودة، ثم يبني البرنامج وينسخ الأدوات بجانب EXE.
5. ستجد الملف في:
   `src\bin\Release\net8.0-windows\win-x64\publish\MobileTransferPro.exe`

إذا منع Windows تشغيل السكربت، افتح PowerShell يدوياً داخل مجلد المشروع واستخدم الأمر أعلاه. لا تعطّل الحماية العامة لويندوز.

## تجهيز هاتفَي Android
1. خذ موافقة صاحب كل هاتف قبل الوصول إلى بياناته.
2. فعّل خيارات المطوّر ثم USB debugging على الهاتفين.
3. وصّل الهاتفين بالكمبيوتر، وافق على رسالة الثقة/مفتاح RSA على كل هاتف، واستخدم كابلات بيانات جيدة.
4. افتح البرنامج واضغط «تحديث الأجهزة»، ثم اختر المصدر والوجهة يدوياً.
5. جرّب أولاً على ملفات غير مهمة، وتحقق من الملفات على الهاتف الهدف قبل تسليم الجهاز.

## الخصوصية والسلامة
- الملفات تمر مؤقتاً عبر الكمبيوتر. لا تستخدم جهازاً مشتركاً أو غير موثوق.
- خيار حذف النسخة المؤقتة يحاول حذف مجلد العمل الذي أنشأه البرنامج فقط؛ وقد يفشل الحذف إذا كان ملف قيد الاستخدام. تحقق من سجل البرنامج.
- لا تحذف شيئاً من الهاتف المصدر بناءً على نجاح النقل وحده؛ تحقق يدوياً من النتائج أولاً.

## بناء نسخة Windows من السحابة (بدون تثبيت أدوات على كمبيوتر المستخدم)

يتضمن المشروع سير عمل GitHub Actions في `.github/workflows/build-windows.yml`. بعد رفع المشروع إلى مستودع GitHub وتفعيل Actions، يُبنى التطبيق على عامل Windows سحابي وتُحفظ حزمة `MobileTransferPro-Windows-x64.zip` كـ Artifact باسم `MobileTransferPro-Windows-x64`. يمكن تنزيلها من صفحة تشغيل Workflow ثم فك الضغط وتشغيل `MobileTransferPro.exe`. هذه العملية تبني الملفات فقط؛ يجب اختبار النقل على أجهزة فعلية قبل استخدامها مع بيانات الزبائن.
